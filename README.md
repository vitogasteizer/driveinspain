# España Drive

ქართველი მძღოლის გზამკვლევი ესპანეთში.

## ფაილები

- `index.html` — გვერდის სტრუქტურა და ყველა სექციის ტექსტი (სექციები იპოვე `id`-ით, მაგალითად `id="tolls"`).
- `css/style.css` — ფერები, ზომები, დიზაინი.
- `js/data.js` — **აქ შეცვალე პარკირების ფერები და ლექსიკონი.** ყველა ტერმინი ცალკე ჩანაწერია.
- `js/app.js` — მენიუ, ფოტოს გადიდება, სტატუსი (ფასიანი/უფასო დრო).
- `images/` — ფოტოები. ატვირთე აქ და `js/data.js`-ში `img` ველში ჩაწერე ბმული.

## სად რა შეცვალო

| რა გინდა | სად |
|---|---|
| პარკირების ფერის ფოტო | `js/data.js` → `PARKING_COLORS`, `img` ველი |
| პარკირების ფერის ტექსტი | `js/data.js` → `PARKING_COLORS`, `desc` |
| ლექსიკონის ტერმინი | `js/data.js` → `DICT_ROAD`, `DICT_SPAIN`, `DICT_POLICE`, `DICT_ACCIDENT` |
| OTA გრაფიკი და ტარიფი | `index.html` → `id="ota"` |
| ფასიანი დრო (სტატუსი) | `js/app.js` → "ვიტორიის OTA" ბლოკი (`otaStatus`) |
| ოფიციალური წყარო (ბმული) | `index.html` → სექციის ბოლოს, `class="src"` |
| საგანგებო ნომერი | `index.html` → `id="emergency"` |

## ფოტოს დამატება

1. GitHub-ზე: რეპოზიტორია → `images/` → **Add file → Upload files** → ატვირთე.
2. ბმული: `images/ფაილი.jpg` (თუ იმავე საიტზეა) ან სრული მისამართი.
3. `js/data.js`-ში ჩაწერე `img: "images/ფაილი.jpg"`.

## რედაქტირება GitHub-ზე

- ფაილი გახსენი → ფანქრის ღილაკი (Edit) → შეცვალე → **Commit changes**.
- რეპოზიტორიის გვერდზე `.` დააჭირე — ბრაუზერში გაიხსნება რედაქტორი (VS Code ვებ-ვერსია), ინსტალაცია არ სჭირდება.

## გამოქვეყნება (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
